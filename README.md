#  Fleet Utilization Dashboard — Capstone Project

##  Project Overview

This capstone project analyzes fleet utilization and operational performance through a collection of five interactive dashboards.

The dashboards transform fleet data into visual insights that can help stakeholders monitor utilization, identify performance patterns, and make data-driven operational decisions.

##  Project Objectives

- Analyze fleet utilization and operational performance
- Monitor key fleet KPIs
- Identify utilization patterns and trends
- Compare fleet performance
- Identify areas requiring operational improvement
- Present findings through interactive dashboards
